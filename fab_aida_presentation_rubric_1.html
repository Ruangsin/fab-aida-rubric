เกณฑ์การประเมิน

1. ความสอดคล้องของเนื้อหากับ Framework Content–Framework Alignment
เต็ม 1.50
ดีเยี่ยม1.50
ระบุองค์ประกอบ FAB และ AIDA ได้ครบถ้วน เชื่อมโยงกับโฆษณาที่เลือกอย่างสมเหตุสมผลและชัดเจน
ดี1.10
ระบุองค์ประกอบส่วนใหญ่ได้ถูกต้อง เชื่อมโยงกับโฆษณาได้ดี แต่บางจุดยังไม่ชัดเจน
พอใช้0.70
ระบุองค์ประกอบได้เพียงบางส่วน การเชื่อมโยงกับโฆษณายังสับสนหรือไม่ชัดเจน
ควรปรับปรุง0.30
ไม่สามารถระบุองค์ประกอบของ framework ได้ชัดเจน หรือเข้าใจหลักการคลาดเคลื่อน
2. ความถูกต้องของการวิเคราะห์ Accuracy of Analysis
เต็ม 1.25
ดีเยี่ยม1.25
วิเคราะห์ถูกต้องตามหลักวิชาการ ใช้คำศัพท์และแนวคิดของ FAB/AIDA อย่างแม่นยำ
ดี0.90
วิเคราะห์ถูกต้องเป็นส่วนใหญ่ มีข้อผิดพลาดเล็กน้อยที่ไม่กระทบภาพรวม
พอใช้0.60
มีข้อผิดพลาดในการวิเคราะห์หลายจุด ใช้แนวคิดคลาดเคลื่อนบางส่วน
ควรปรับปรุง0.30
วิเคราะห์ผิดหลักการเป็นส่วนใหญ่ ไม่เข้าใจแนวคิดหลักของ framework
3. ความครบถ้วนของเนื้อหา Completeness
เต็ม 1.25
ดีเยี่ยม1.25
นำเสนอครบทุกองค์ประกอบของทั้งสอง framework พร้อมตัวอย่างประกอบจากโฆษณาจริง
ดี0.90
นำเสนอครบเกือบทุกองค์ประกอบ ขาดตัวอย่างประกอบในบางจุด
พอใช้0.60
ขาดองค์ประกอบสำคัญบางส่วน เนื้อหายังไม่ครบถ้วนตามที่กำหนด
ควรปรับปรุง0.30
เนื้อหาขาดหายไปมาก ไม่ครบตามที่กำหนดของทั้งสอง framework
4. ทักษะการนำเสนอ Presentation Skills
เต็ม 1.00
ดีเยี่ยม1.00
นำเสนอมั่นใจ ชัดเจน ควบคุมเวลาได้ดี สื่อสารกับผู้ฟังได้อย่างมีประสิทธิภาพ
ดี0.70
นำเสนอได้ดี มีความมั่นใจ แต่การควบคุมเวลาหรือการสื่อสารยังไม่สมบูรณ์แบบ
พอใช้0.40
นำเสนอได้ตามเนื้อหา แต่ขาดความมั่นใจหรือควบคุมเวลาไม่ดี
ควรปรับปรุง0.20
นำเสนอไม่ชัดเจน ขาดความมั่นใจ หรือควบคุมเวลาไม่ได้
